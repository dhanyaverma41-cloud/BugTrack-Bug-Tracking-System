# BugTrack-Bug-Tracking-System
An end-to-end web application developed to manage, track, and monitor software bugs efficiently.

— Tools & technologies used: React.js, Node.js, Express.js, MongoDB, Tailwind CSS, JWT, Postman
— Developed a complete bug tracking system with role-based login for Admin, Developer, and Tester. The application allows users to report and filter bugs, update bug status through different stages, view dashboard analytics, and receive automatic notifications for new bugs and status changes.
